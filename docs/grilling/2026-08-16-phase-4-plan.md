## Findings against the plan, and what changed

1. **The fixture master.db is useless without its key.** The fixture is
   SQLCipher-encrypted with the owner's key, so "deliver a fixture" (D10)
   implicitly means "deliver the fixture plus its key, or an unencrypted
   export". Resolution: D10's owed-inputs list is sharpened to include the
   key or a decrypted export; quickstart already assumes it. Blocks the R3
   spike, so it is the first thing phase 6 waits on.
2. **Guard's process detection is Mac-only and untestable here.** Whether
   "Rekordbox is running" detection works can only be proven on the Mac.
   Resolution: the guard's interface returns a refusal object that tests
   inject through the fake `rb` adapter; the real detection is on the Mac
   verification list (quickstart US3), an accepted residual with owner
   Martien.
3. **The 30s promise quietly assumed small playlists.** At the 1.000-track
   bound, 1.000 × 30.000 fuzzy comparisons can exceed a minute. Resolution:
   the constraint already scopes 30s to 100 tracks; the plan adds SSE
   progress (ADR 0014) so long syncs are visibly alive, and rapidfuzz's
   batched scoring keeps the ceiling acceptable. No number was changed.
4. **Spotify's API access for new apps is shifting ground.** Late-2024 policy
   removed preview URLs and several endpoints for new apps; artist genres
   could be next. Resolution: enrichment already sits behind the GenreSource
   seam (ADR 0013) with MusicBrainz as the second adapter; if artist genres
   are unavailable to a dev-mode app, the secondary becomes primary and the
   coverage spike (R1) measures that world instead. The Playback SDK spike
   (R2) carries the same class of risk with its own fallback.
5. **Backup headroom was an adjective.** "Refuse when a backup would not
   fit" needed a number. Resolution: guard refuses a write when free disk is
   below 2× the current master.db size; recorded here, implemented in
   `guard.py`, tested via the fake adapter.
6. **SSE through the Vite dev proxy** buffers by default and would look like
   a hang in dev. Resolution: noted as an implementation detail for the dev
   proxy config task; no design change.
7. **Player token scope creep.** The Web Playback SDK needs the `streaming`
   scope plus user-read scopes; asking for them later means re-consent.
   Resolution: the PKCE flow requests the full v1 scope set on first connect;
   listed in the auth task.

with a headroom guard (ADR 0010), incremental enrichment (ADR 0013), SSE
(ADR 0014), schema-first client generation (ADR 0015), and the proof-of-value
cuts in plan.md. No constraint from `docs/constraints.md` was found unmapped;
the plan's constraint table held under review.
