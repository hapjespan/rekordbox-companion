# Phase 3 grilling record, 2026-08-16

Elicitation output of phase 3 (Constraints). Non-functionals grilled with the
owner on 2026-08-16; one round sufficed, every answer below is a number or an
explicit "unbounded, accepted". The resulting constraints live in
`docs/constraints.md`; decisions that close off design options are recorded as
ADRs.

## Decision log delta

Continues the numbering from the phase 1 record (D5–D10):

- D11: The system is dimensioned for a 30.000+ track Collection; every
  performance criterion is verified at 30.000, superseding the spec's
  10.000+ floor upward.
- D12: Playlists are capped at 999 tracks; a larger playlist is refused with a
  message naming the limit. Full report at the cap within 5 minutes.
- D13: Backups are zip-compressed, the newest 10 are kept, pruning happens only
  after a new successful, verified backup. Zip over rar: rar is a proprietary
  format needing external tooling; zip is in the standard library and equally
  serves the purpose.
- D14: External sources (enrichment, store-link lookup) must be free of
  recurring cost: free API tiers only. ADR 0010.
- D15: No deadline; the owner paces the project. Unbounded, accepted.
- D16: Target machine Apple Silicon M3, 16 GB RAM; free disk unbounded,
  accepted, guarded by the pre-backup disk check.
- D17: Own-data retention unbounded (accepted); no transcode cache in v1;
  availability by restart; the companion's own database is covered by the
  machine backup.
