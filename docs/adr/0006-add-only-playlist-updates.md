# Companion-created playlists are updated add-only

Re-syncing the same Spotify playlist updates the previously created Rekordbox
playlist instead of creating a new one, and that update only ever adds tracks:
the companion never removes or reorders tracks in Rekordbox. Considered
alternatives: a new playlist per apply (rejected by the owner: clutters the
tree), full mirroring (rejected: would destroy manual curation done inside
Rekordbox). Add-only keeps the write surface minimal and makes losing manual
edits impossible; removal stays a manual act in Rekordbox. Newly acquired
Missing Tracks flow in automatically on the next sync of the same playlist.
Decided in phase 1 grilling (D5), 2026-08-16.
